# CineMatch 🎬

A movie recommendation application built using Python and Streamlit.

## Features
- Movie recommendations
- Trending movies
- Movie search
- Surprise Me
- Movie posters and details

## Technologies
- Python
- Streamlit
- Machine Learning
- TF-IDF
- TMDB API
- Hugging Face

## Run Application

pip install -r requirements.txt

streamlit run app.py
